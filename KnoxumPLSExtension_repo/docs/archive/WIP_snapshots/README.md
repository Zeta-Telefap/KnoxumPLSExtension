# Архив WIP-снапшотов

Сюда вынесены старые файлы высоких стен, которые заменены одним `src/Features/HighWalls.cs`.

| Файл | Почему в архиве |
|---|---|
| `HighWallsGenerator.fixed.cs.txt` | Первая версия генератора. Quad-геометрия (UV 0..1 → тянет весь атлас), нет работы с `_LightMap`. Заменён. |
| `HighWallsGenerator.rewrite.cs.txt` | Вторая версия. Архитектурно лучше (свои UV в квадранте стены, атлас по комнате), но стены строятся **вниз** от поднятого тайла, из-за чего двери/объекты/лампы (дети тайла) оказываются на верхнем слое, а не на полу. Логика перенесена в `HighWalls.cs` с исправлением. |
| `HighWallsObjects.cs.txt` | Привязка объектов и рамп. Дублирует патчи `RefreshCells`/`LoadTile`/`SetShape` → конфликтовал бы с новым кодом. Рампы — отдельная задача, вернёмся к ней после стабилизации стен. |
| `KnoxumRampSelectionUI.cs.txt` | UI рамп; зависит от `HighWallsObjects` и `KnoxumRampData`, поэтому лежит рядом. |

Расширение `.txt` — намеренно: файлы остаются в истории git и читаемы, но **не компилируются**
(иначе дубли классов и двойное применение Harmony-патчей).

Всё это можно вернуть одной командой:
```bash
git checkout HEAD~ -- <путь к файлу>
```
